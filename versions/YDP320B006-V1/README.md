## 产品简介

OSPTEK **3.2 寸 240×320 TFT** 是一款 **SPI** 接口彩色显示模组，驱动为 **ST7789P3**。适合手持终端、仪表与小型竖屏 HMI 等场景。

规格标识（仓库名）：`tft-3.2-240x320-spi-st7789`

当前模组版本：**YDP320B006-V1**。外形与电气细节以 [`docs/YDP320B006-V1_外形图.pdf`](./docs/YDP320B006-V1_外形图.pdf) 为准。

## 规格参数

| 项目 | 规格 |
| ---- | ---- |
| 尺寸 | 3.2 英寸 |
| 类型 | TFT / IPS（彩色） |
| 分辨率 | 240×320 |
| 接口 | SPI（4-wire） |
| 驱动 IC | ST7789P3 |
