## Overview

OSPTEK **3.2″ 240×320 TFT** is a **SPI** color display module driven by **ST7789P3**. Suited to handheld devices, instruments, and compact portrait HMI.

Spec ID (repository name): `tft-3.2-240x320-spi-st7789`

Current module version: **YDP320B006-V1**. Outline and electrical details follow [`docs/YDP320B006-V1_外形图.pdf`](./docs/YDP320B006-V1_外形图.pdf).
